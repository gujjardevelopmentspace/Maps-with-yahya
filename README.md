Maps-with-yahya

A simple, interactive map project with step-by-step instructions.

Overview

This project demonstrates how to integrate a map into a simple web application—ideal for learning frontend mapping techniques using HTML, CSS, and JavaScript.

Features

Displays an interactive map (using Google Maps, Leaflet, or similar)

Centered at a pre-defined location with customizable zoom

Supports adding markers based on coordinates or user input

Includes written instructions for setup and customization

Lightweight and responsive design

Technologies

HTML5 – Structure and map container

CSS3 – Styling and responsiveness

JavaScript (ES6+) – Map initialization and interactivity

Optional libraries: Leaflet or Google Maps API

Project Structure

Maps-with-yahya/
│── index.html – Main entry point
│── style.css – Stylesheet
│── script.js – Map logic
└── LICENSE – Apache 2.0 license

Usage Instructions

Clone the repository:
git clone https://github.com/gujjardevelopmentspace/Maps-with-yahya.git

cd Maps-with-yahya

Open index.html in your browser.

Follow the on-page instructions to:

Configure the map provider

Set map center and zoom level

Add markers or custom features
